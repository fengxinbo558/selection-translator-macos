# 划译

划译是一个 macOS 15+ 原生翻译工具。它能输入文字翻译、翻译其他应用中选中的文字，也能框选图片、网页或视频字幕并通过 Apple Vision 在本机识别后翻译。

## 使用方式

1. 双击 `dist/划译.dmg`。
2. 把“划译”拖到“应用程序”，再双击启动。
3. 翻译框会直接出现；粘贴或输入文字后会自动翻译成英语。
4. 目标语言是窗口顶部收起的下拉框，点开可从 21 种系统语言中切换。
5. 点击“复制译文”将结果放进剪贴板。

要使用自动读取和替换：

1. 点击翻译框右上角齿轮，在权限区点击“打开‘辅助功能’设置”。
2. 在 TextEdit、备忘录、浏览器编辑框等位置选中文字。
3. 按默认快捷键 `⌘T`。读取期间会立即显示进度提示，随后直接翻译成设置里的默认语言（初始为英语）。
4. 可编辑位置会被自动替换；只读位置在小窗中显示译文并提供复制。
5. 小窗顶部的语言下拉框可直接换语言并原地重新翻译。

要翻译屏幕中无法选中的文字：

1. 按默认快捷键 `⌥⌘T`，或点击主窗口顶部的“截图翻译 ⌥⌘T”。
2. 首次使用时按提示在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中允许划译。
3. 开启权限并返回划译后会自动进入框选；拖动框选图片、网页或视频字幕，按 `Esc` 取消。
4. 识别出的原文可在同一个窗口中修改，译文会自动更新。

关闭翻译框后，划译仍会留在菜单栏。再次双击应用会重新打开翻译框。菜单栏中的“划译”图标可以翻译当前选区、启动截图翻译、打开输入翻译器和设置。

`⌘T` 在浏览器等应用中通常用于新建标签页；划译作为全局快捷键运行时会优先响应。需要保留原应用的 `⌘T` 时，可以在设置中录制其他组合。

## 构建

需要 macOS 15+ 和 Swift 6 / Xcode 16+ Command Line Tools。

```bash
swift build
swift test
./Scripts/build-app.sh
```

打包完成后会生成：

- `dist/划译.dmg`：推荐的双击安装包。
- `dist/划译.zip`：备用压缩包。
- `dist/划译.app`：直接运行的应用包。

## 权限与隐私

- 不授权 Accessibility 也能使用粘贴/输入翻译。
- Accessibility 权限只用于读取当前选区、回到原应用并替换文字。
- 默认使用 Apple Translation 框架在设备上完成，不联网。
- 设置中可以主动启用 DeepSeek、OpenAI、Claude、Gemini 或 OpenAI-compatible 云端翻译。
- 云端模式只发送用户主动翻译的文字；API Key 按服务商分别存入 macOS 系统钥匙串，不写入普通设置。
- 截图和 OCR 结果只驻留内存，不写入临时文件。
- 应用不保存原文、译文或翻译历史。
- 在少数不支持 Accessibility 选区接口的编辑框中，应用会短暂借用剪贴板完成复制或粘贴，并在操作后恢复原剪贴板内容。
- 密码框和受保护文字不会被读取。

## 语言包

首次使用某个语言组合时，macOS 可能询问是否下载对应的翻译语言包。下载和管理位置为“系统设置 → 通用 → 语言与地区 → 翻译语言”。

## 已知限制

- 只读网页或不可编辑区域无法原位替换，应用会提供“复制译文”。
- 某些自绘编辑器不暴露标准 Accessibility 选区，读取或替换能力取决于宿主应用。
- 自动语言识别对非常短的文字可能不准确。
- 当前版本仅支持 macOS 15 及以上系统。
