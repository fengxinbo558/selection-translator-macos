# 划译 macOS 图标设计

## 目标

为“划译”提供清晰、可识别的正式应用图标，替换当前由 macOS 显示的通用占位图。图标需要在 Finder、Dock、启动台和小尺寸列表中保持辨识度。

## 候选方向

1. **翻译气泡**：蓝色渐变圆角方形，中央为白色对话气泡和简化的双向转换符号。含义最直接，小尺寸可读性最好。
2. **取景框翻译**：蓝青色圆角方形，将截图取景框与对话气泡结合，强调截图翻译能力。
3. **双语切换（正式采用）**：蓝紫色圆角方形，用拉丁字形与汉字笔画及双向箭头表达多语言转换。

## 视觉约束

- 1024×1024 主图，正视角，macOS 风格圆角方形。
- 不使用细小文字、复杂背景、照片质感或水印。
- 核心标记留足安全边距，在 16–32 像素下仍能辨认。
- 颜色以蓝色为主，和应用现有蓝色翻译标记保持一致。

## 接入方式

- 三套候选图保存在 `Resources/IconCandidates/`。
- 按用户选择，将第三套“双语切换”制作成 `Resources/AppIcon.icns`。
- `Info.plist` 声明 `CFBundleIconFile = AppIcon`。
- 构建脚本将图标复制到应用包的 `Contents/Resources`。

## 验收标准

- 应用包不再显示通用占位图。
- Finder/Dock 能显示正式图标。
- 图标资源覆盖 16、32、128、256、512 和 1024 像素层级。
- 应用构建、签名和现有测试继续通过。

## 自检

方案未使用细小文字，避免缩小后糊成一团；三套方向都围绕翻译核心功能，没有引入与产品无关的装饰。正式图标采用用户选定的第三套“双语切换”。
