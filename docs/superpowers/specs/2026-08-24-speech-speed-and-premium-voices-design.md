# 朗读速度与高质量本机声音设计

## 目标

原文和译文朗读共用一个持久化语速选择，提供 `1×`、`1.25×`、`1.5×`、`2×`、`3×`、`4×`、`5×`。声音优先使用这台 Mac 已下载的 Apple Premium 或 Enhanced 语音，不把朗读文字发送到网络。

## 界面

1. 主翻译窗口顶部增加紧凑的“语速”下拉框，默认 `1×`。
2. 修改语速立即作用于当前播放和后续播放，原文与译文保持一致。
3. 选择会保存，关闭或重新启动软件后继续使用上一次语速。
4. 小型选区翻译窗口使用同一保存值，不额外挤入一个重复控件。

## 播放实现

1. Apple 的直接朗读速率上限只能达到默认值约两倍，因此先用 `AVSpeechSynthesizer.write` 生成本机语音缓冲，再通过 `AVAudioUnitTimePitch` 播放。
2. `AVAudioUnitTimePitch` 保持音高并支持 1×到5×的真实播放倍率；修改倍率时直接更新当前音频节点。
3. 新朗读开始时取消旧的生成和播放。过期的生成回调不能覆盖当前按钮状态。
4. 临时音频只在系统临时目录中存在，播放完成或取消后删除，不保存朗读历史。

## 声音策略

1. 同语言下按 `Premium > Enhanced > Siri > 普通` 排序，并避开 Eloquence 与趣味电子声。
2. 下载 Apple 官方高质量声音后无需重装应用；下次朗读自动识别并优先使用。
3. 英语优先尝试网上常被推荐的 Ava Premium、Samantha Enhanced；中文、日语、韩语选择本机实际可下载的最高质量声音。

## 云端边界

- OpenAI 官方推荐 `marin` 和 `cedar` 作为高质量云端声音，但当前 Mac 没有 OpenAI API Key。
- 本次不接入非官方免 Key 接口，也不上传朗读文字。代码结构保留未来接入正式云端 TTS 的空间。

## 验证

- 单元测试覆盖所有可选倍率、范围限制、保存与恢复。
- 单元测试覆盖 Premium/Enhanced 优先级。
- 全量测试和发行版构建通过。
- 安装后验证原文、译文均能播放，并分别切换 `1×`、`3×`、`5×`；播放状态和停止按钮正常。
