# 原文与译文分别朗读设计

## 目标

手动翻译窗口同时提供“朗读原文”和“朗读译文”。两个按钮分别播放对应文字，用户不需要复制内容或打开其他界面。

## 交互

1. “朗读原文”位于输入区标题栏、清空按钮左侧。
2. 结果区现有“朗读”改名为“朗读译文”。
3. 当前正在播放的按钮显示“停止”，另一个按钮仍显示自己的朗读名称。
4. 播放过程中点击同一个按钮会停止；点击另一个按钮会停止当前内容并立即播放另一段，不能叠音。
5. 原文或译文发生变化、窗口关闭时停止旧朗读。

## 语言与状态

- 原文使用输入文字的检测语言选择系统声音，支持中文、英语、日语和韩语；已知英文缩写按英语朗读。
- 译文继续使用实际目标语言选择系统声音。
- 声音优先选择已安装的 Siri、Premium 或 Enhanced 自然语音，避开 Eloquence 和趣味电子声；没有高质量声音时才使用对应语言的普通声音。
- 使用接近日常说话的语速，不额外改变音调。
- 朗读器记录当前播放对象的身份，旧语音的结束回调不能清除新语音的播放状态。
- 空文字对应的朗读按钮不可用。

## 不采用的方案

- 两个独立朗读器：可能同时播放两段语音，造成叠音。
- 单一按钮加选择菜单：每次朗读多一次操作，不符合快速分别朗读的需求。

## 验证

- 单元测试覆盖原文语言标识的选择。
- 单元测试覆盖已安装首选自然声音的选择。
- 全量自动测试通过。
- 安装后的真实界面分别点击原文和译文按钮，确认只有当前按钮显示“停止”，并可互相切换。
